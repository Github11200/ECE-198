Exercise session tracker

Set participant targets, monitor exercise activity, and review the results of a supervised group session.

Open Admin Panel Participant portal

The Admin Panel connects to the local tracker. Participant programme pages contain sample records.

Session workflow

One exercise and one group at a time.

  1. 1

    Set up the group

    Choose an exercise, assign participant IDs to camera lanes, and set a rep target for each person.

  2. 2

    Monitor the session

    Follow individual rep counts, range cues, and tracking availability while participants exercise.

  3. 3

    Save and review

    End the session to save each participant’s results. Review short attempts, tracking notes, and the workout report.

Exercise options

Select the movement and review its fixed demo criteria in the Admin Panel.

Strength
Seated right-arm curls, squats, pushups
Chair-based movements
Seated knee extensions, shoulder raises, marches, and sit-to-stand
Saved results
Reps completed, range target reached, tracking coverage, and per-participant review notes

About the prototype

A Waterloo ECE 198 project for tracking exercise activity and range during supervised CCCARE sessions. Participants use numbered IDs assigned by the instructor.
